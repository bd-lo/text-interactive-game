## 阅读指南

- 想先了解“做什么、为什么”：读第 1–3 章。
- 要开始搭骨架：读第 4、5、6、7、16、17 章。
- 负责 Agent 与规则/判定：读第 8、9、10、11 章。
- 负责模型调用、制造、状态与安全：读第 12、13、14、15 章。
- 负责测试、依赖与许可证：读第 18、19 章。
- 负责 Web 前端（Vue 3）：读第 23 章，并参考第 2、3、4、6、12、15 章。
- 所有开发者：第 22 章的进度文档制度必须执行；每章开头的“检索关键词 / 打开确认的仓库列表”用于复核选型依据。

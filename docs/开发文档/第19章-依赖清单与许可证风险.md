### 19.1 依赖分层与版本锁定策略
依赖分三组管理，避免运行时装测试库：**运行时（runtime）**、**开发/测试（dev）**、**仅参考设计（reference-only）**。锁定机制：
1. `pyproject.toml` 写 `requires-python = ">=3.10,<3.13"`，uv 解析会自动避开要求更高 Python 的版本（如 SQLAlchemy 解析到 2.0.57），`uv.lock` 一次性锁定全套传递依赖。
2. CI 与验收环境一律 `uv sync --frozen`；禁止 `pip install` 临时改环境；lock 变更必须单独 PR 并跑全量测试。
3. 升级窗口每月一次，升级后必须重跑 golden 回放；`fastapi`/`pydantic`/`langgraph`/`litellm` 只接受 patch 或 minor，大版本升级按第 12 章评估。
4. dev 依赖不参与 runtime 镜像构建；软件物料清单（SBOM, Software Bill of Materials）只对 runtime 交付物生成。
5. Node 仅构建期：前端依赖单独放 `web/package.json` + `pnpm-lock.yaml`（`pnpm install --frozen-lockfile`），不进入 Python 运行时镜像与运行时 SBOM；前端扫描用 `pnpm audit`，版本 pin 见 19.7。

推荐命令（CI 的 `deps` job）：
```bash
uv sync --frozen
uv export --frozen --format requirements-txt --no-hashes > artifacts/requirements.lock.txt
uv run pip-licenses --format=markdown --with-urls > artifacts/licenses.md
uv run pip-audit -r artifacts/requirements.lock.txt
uv run cyclonedx-py environment --of JSON -o artifacts/sbom.json
```
**复用判断与拼接边界**：pip-licenses 出“人读清单”、pip-audit 查 CVE、cyclonedx 出 SBOM，三者互补且在 dev 组；pip-tools 与 uv.lock 重叠，放弃。扫描必须基于 `uv sync --frozen` 后的真实环境（含传递依赖），只扫直接依赖会漏报；CI 遇 GPL/AGPL/未知许可证即阻断合并，例外须在 allowlist 登记理由与到期日；GPL-3.0 的 reuse-tool 只本地手动用，不进 CI 依赖。

### 本章结论
1. 依赖分运行时/开发/仅参考三组；`uv.lock` + `--frozen` 是唯一锁定机制，`requires-python` 写成 `>=3.10,<3.13` 可让解析器自动避开要求更高 Python 的版本。
2. 关键事实：Python 3.10 已于 2026-10-01 EOL；12 个依赖的最新版已要求 ≥3.11/≥3.12，必须按 19.2 的 pin 表锁定（尤其 `SQLAlchemy 2.0.57`、`pydantic-settings 2.15.0`、`cachetools 7.3.0`）。
3. 运行时依赖全部为 MIT/Apache-2.0/BSD 类宽松许可，可闭源分发；唯二需特殊处理：LiteLLM 的 `enterprise/` 目录、MPL-2.0（orjson/hypothesis）。
4. 许可证红线：`tldw_server`（GPL-3.0-only）、`open-tabletop-gm`（AGPL-3.0）只能参考设计；`MnesOS`、`interactive_fiction_game` 无 LICENSE 文件，禁止拷贝；Evennia 因 Python ≥3.12 与状态权威冲突放弃。
5. 可执行建议：M1 的 CI `deps` job 固定执行 `pip-licenses + pip-audit + cyclonedx` 三件套，allowlist 初始只放 19.3 表中“允许”的仓库，任何新增依赖先过“依赖方向 + 许可证 + 3.10 兼容”三道门（与第 4 章结论一致）。
6. v0.2 前端 npm 依赖（`vue 3.5.45`、`vue-router 5.4.0`、`pinia 4.1.0`、`vite 8.3.6`、`typescript`、`ajv 8.20.0`、`vitest 5.1.0`、`@vue/test-utils 2.5.1`、`playwright 1.65.0`、`axe-core`）全部 MIT/Apache-2.0/MPL-2.0（axe-core 为 dev-only），锁 `pnpm-lock.yaml`；Node 24.x LTS 仅构建期，运行期零 Node 依赖。

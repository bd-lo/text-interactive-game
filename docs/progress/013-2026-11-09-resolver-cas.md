> 切片目标一句话：实现纯函数 `Resolver`（确定性裁决、working_state 逐条重校验、草稿事件加审计键）与确定性 `DeterministicCharacterAgent`，并把多角色链路接进编排层（队列 → 裁决 → CAS 提交，最多 3 次只重裁决）｜ 验收命令：`uv run pytest tests/integration/test_resolver_cas.py` ｜ 里程碑 M3 ｜ 编号区间 010–014 ｜ 执行/验收：multi-actor-dev（AI）/ lead（集成、验收、提交）

## 1. 目标与验收命令

- 目标（第 11 章 §11.1–§11.3、第 21 章 §21.2.2/§21.2.6）：
  - `Resolver.resolve(entries, snapshot, judgements=None)` 纯函数：不调模型、不写库、不读时钟/仓储；逐条前置条件校验（`RuleEngine.evaluate_preconditions`）→ `ToolGate.dispatch` 执行 → `applied_events` 草稿事件 `params` 追加 `proposal_id`/`resolution_id`；每条 applied 后 `working_state.apply(events)`，后序提案基于前序结果重校验（资源竞争/目标冲突）。
  - `DeterministicCharacterAgent`：按 `domain/scenario.py::M3_NPC_PLANS` 计划表产出 ≤2 条 `priority=50` 提案，只消费 `PerceptionSlice`、零 LLM、可回放（D-M3-2）。
  - 编排层：玩家破坏性动作 + 角色 Agent 提案入 `ProposalQueue`；`GameEngine.submit` CAS 冲突最多 3 次尝试，**只重裁决、不重解析/不重叙事**；失败零写入。
- 验收命令与结果：`uv run pytest tests/integration/test_resolver_cas.py -q` → **7 passed**；单元/安全：`tests/unit/test_resolver.py` 41 passed + `tests/security/test_resolver_security.py` 20 passed；全量 **960 passed**。

## 1. 目标与验收命令

- 目标（≤90 分钟）：用媒体查询在窄屏放大按钮/chips/下拉/分页/图标按钮/开关/折叠摘要等触控目标到
  ≥44×44（或等效的可点标签区域）；1280px 视觉密度与桌面 e2e 断言不受影响。
- 验收命令/断言（先定后写）：
  - `pnpm --dir web test` → **69 files / 481 tests** 全绿（`mobileLayout.test.ts` 8 例断言触控规则/断点/换行）
  - `pnpm --dir web typecheck` → 通过；`pnpm --dir web build` → 通过且两次构建 SHA256 一致
  - `node scripts/e2e-web.mjs` → **32/32 步、205/205 断言**（`mobile.375` 步在 9 个页面抽样可见交互控件，
    全部 `getBoundingClientRect() >= 43.5×43.5`；1280px 对照按钮 <44 高）
- 不做什么：不放大桌面端控件（保持 1280 密度）；不对内联文本链接强制 44×44（WCAG 2.5.5 inline 例外）；
  不引入手势/组件库。

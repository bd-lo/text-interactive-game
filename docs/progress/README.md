# 开发进度文档目录

每次开发会话（= 一个可独立验证的功能切片）结束时，在本目录新建进度文档，命名格式：

`NNN-YYYY-MM-DD-<主题>.md`

- `NNN`：三位数字，全局唯一、单调递增、永不复用，按开发文档第 22.3 节的里程碑区间分配（M1 001–004、M2 005–009、M3 010–014、M4 015–018、M5 019–024）；
- `YYYY-MM-DD`：会话结束日（Asia/Shanghai，UTC+8）；
- `<主题>`：ASCII kebab-case，2–5 个英文词，如 `bootstrap-skeleton`、`turn-loop`，禁止空格、中文、大写；中文说明写进正文。

示例：`001-2026-11-15-bootstrap-skeleton.md`

新建后必须同步更新 `docs/PROGRESS.md`（总体进展总览），更新里程碑状态与完成度。模板见《开发文档》第 22.4、22.5 节。
